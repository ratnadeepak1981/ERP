## 2. API Authorization & Scope Enforcement Architecture

- **Attribute Decoration:** Every operational controller action is decorated with `[RequirePermission("PERMISSION_CODE")]` and inherits from `BaseApiController`.
- **Dynamic Policy Provider:** `PermissionPolicyProvider` registers dynamic policies prefixed with `Permission:`.
- **Authorization Handler:** `PermissionAuthorizationHandler` inspects the authenticated user's JWT `permission` claims, supporting `.EDIT` / `.UPDATE` aliases and returning `HTTP 403 Forbidden` if unauthorized.
- **Company & Branch Scope Validation:**
  - `UserAccessService.CanAccessCompanyAsync` validates that the user possesses an active `UserRoleScope` entry for the requested `companyId`.
  - `UserAccessService.CanAccessBranchAsync` validates branch-level scope when branch-level restrictions apply.
  - Cross-company or cross-branch manipulation by unauthorized users returns `HTTP 401 Unauthorized` or `HTTP 403 Forbidden`.
  - Platform users are blocked from tenant operational domain controllers (`return Forbid()`).
